# 第一版跨会话长期记忆

记忆模式是智能体统一配置，应用于此智能体所有用户。记忆内容按当前用户 + 当前智能体隔离，跨同一智能体的会话生效，不跨用户或智能体共享。
存储使用 PostgreSQL / MyBatis，V16、V17、V18。无需 Embedding 服务或 pgvector。

## 记忆模式

智能体配置区与 Skills、MCP 同级的“记忆模式”折叠项三选一，设置按智能体持久化：
- NONE 无记忆：仅发送当前问题，跳过历史消息、会话摘要、长期记忆召回和自动记录。
- CONTEXT 上下文记忆：使用当前会话历史和摘要，不读取或自动记录长期记忆。
- CROSS_SESSION 跨会话记忆：使用当前会话上下文，并启用长期记忆召回和自动记录。
新配置默认 CONTEXT。V18 将此前各用户相同的模式合并为智能体统一模式；若此前各用户模式冲突，则使用 CONTEXT。迁移使旧待整理任务失效，记忆内容保留。
选择不删除聊天记录或已存记忆；切回上下文模式后可以继续使用已有历史。
正在生成回答时不能切换模式。运行轨迹 RUN_STARTED 包含实际 memoryMode。
GET/PUT /api/agents/{agentId}/memory-mode，JSON为 {"mode":"CONTEXT"}。
原 long-memory/mode 及 policy 接口兼容旧客户端，也修改智能体统一模式：true 映射 CROSS_SESSION，false 映射 CONTEXT。

## 自动提取

本版使用纯本地规则，不额外向外部模型发送消息，不消耗提取 Token。
只处理上线后新完成的成功对话中的用户原文，不处理模型回答、工具结果或旧历史。
支持独立完整句子，多个句子可用句号、分号或换行分开：
- 以后请用中文回答（支持英文、英语、简体中文、繁体中文）
- 以后回答请简洁一些（支持详细一些、先给结论、使用列表）
- 以后默认查询苏州工厂（支持今后、查询时默认、使用、看）
- 我的默认业务范围是注塑模具
- 我的岗位是模具工程师
- 我长期负责注塑模具
- 我所在的部门是制造部

不支持任意自然语言推断；疑问句、否定、引文、假设不匹配。
含常见凭证/身份/银行卡关键词的句子跳过。这是保守规则，不保证识别所有敏感内容。
同 key 的后续明确陈述更新旧值；自动生成内容必须由用户核对。

回答与待整理任务在同一事务提交，任务每3秒领取一条。
PG SKIP LOCKED、90秒租约、claim令牌避免多实例同时提交，进程中断可恢复。
崩溃重领最多3次，正常异常任务标为failed，不无限重试。
任务记录状态、来源、提取器 local-rules-v1 以及0 Token。
任务只有用户/智能体/会话/轮次引用，不另复制整段消息。
每条记忆保存来源句子、来源会话和请求，便于核对。

## 召回

每轮发送前读取当前用户/智能体的启用且未过期记忆：
偏好和默认条件直接使用；事实通过英文关键词或中文相邻双字匹配。
这不是语义检索，不保证同义词召回。
按更新时间取最多8条，正文约3000字符预算。
与当前会话摘要一起作为背景送入已有对话模型；本次用户输入及系统规则优先。
召回的长期记忆与其他上下文一样会出现在模型请求中，并计入原有对话Token。
轨迹使用 MEMORY_LOADED 节点标记召回，提取任务状态在长期记忆面板查看。

## 管理

智能体对话区域默认折叠的“长期记忆”面板：
- 查看、手动新增、编辑、启用/禁用、设置有效期、删除。
- 切换到上下文或无记忆模式停止自动记录和长期召回，保留已存内容。
- 切换模式使已有排队任务失效，重新打开也不追补关闭前任务。
- 人工修改或禁用的条目不会被自动提取覆盖。
- 删除清空正文与来源，保留不可见的key墓碑，防止后台重新生成。
  如需重新使用相同key，后续可增加显式恢复功能；当前使用新key手动新增。
- 每个用户/智能体最多100条有效管理记录，更新使用version防止并发覆盖。
- 管理员也没有读取其他用户私有记忆的特权。
- 历史会话不回填；无需重启Python服务。

接口前缀 /api/agents/{agentId}/long-memory：
GET 列表/开关/最近10项任务，POST 新增，
PUT /policy 切换开关，PUT /{id} 修改，DELETE /{id} 删除。
写入接口沿用登录和CSRF保护，修改/删除传入version。
