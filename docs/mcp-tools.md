# MCP 工具网关与 ReAct 使用说明

当前请求路径：

用户消息 → AgentChatService → 模型返回 tool_calls → ToolExecutor → MCP Client
→ 业务 MCP Server → 工具结果 → 模型继续判断 / 生成最终回答

工具网关作为后端模块实现。当前没有拆成独立微服务。
本版支持 Streamable HTTP、Bearer Token、文本 / 结构化结果和 MCP 工具。
暂不支持 stdio、旧版 SSE、人工审批和 OAuth。

## 本地体验

1. 重启 IDEA 后端；V4 迁移自动建立 MCP 服务、工具、授权和审计表。
2. 在项目根目录运行：node demo/mcp-server.mjs
3. 前端进入「MCP 工具管理」，注册 http://127.0.0.1:8090/mcp，Token 留空。
4. 点击「发现 / 同步工具」，发现后工具默认启用，可在弹窗中查看参数或手动禁用。
5. 在模型管理中确认所选模型支持工具调用，勾选「支持工具调用」。
6. 智能体详情打开「绑定业务工具」，勾选该 MCP 服务并保存。
7. 新会话输入「请查询客户 C001 的资料」。演示仅包含 C001、C002 两条虚构数据。
8. 回答下展开「查看工具执行记录」，查看成功、拒绝或失败状态。

演示服务仅监听 127.0.0.1:8090。可设置 DEMO_MCP_TOKEN 启用演示鉴权；
平台注册时填写相同 Token。凭证在数据库中加密保存，不返回前端、不发送给模型。
真实业务服务地址与凭证由管理员维护。

## 接入业务服务

直接在 MCP 工具管理填写业务服务的 HTTP(S) 地址和鉴权配置，无需配置目标白名单。
地址不允许嵌入用户名密码、查询参数或片段，连接不会自动跟随重定向。

工具默认启用，不再需要只读确认，也不再按只读标记限制绑定和执行。
手动禁用会在后续同步中保留；服务移除的工具会停用，再发现时恢复此前的启停设置。
停用服务 / 工具后会在下一次执行前重新校验。
绑定工具使用稳定 UUID 别名，避免不同 MCP 服务同名工具冲突。
业务 MCP Server 必须自行执行用户身份与业务数据权限校验。

## 执行约束与记录

- 每个服务最多 2 个并发、每分钟 30 次请求；目前为单进程计数。
- 单次网络操作 1–30 秒，总任务 170 秒。
- 单次任务默认最多 6 次模型调用、12 次工具调用；可按 Agent 配置，工具顺序执行。
- 参数按 JSON Schema 校验，只允许本地引用，禁止外部 Schema 拉取。
- 工具结果按配置限制字符数（1024–32768），超限不给模型。
  这是接收后限制；尚未实现网络响应流的硬字节上限。
- 工具错误作为工具结果反馈模型，不自动重试；模型可调整参数再次调用。
- 累加各次模型调用的 Token 用量；当前仍是非流式回答。
- 审计按本轮 requestId 关联，保存工具名、状态、参数字段名、结果字符数、
  耗时、错误码；不保存参数值、完整工具结果或凭证。
- 对话跨轮上下文目前保留最终问答，工具轨迹可查看审计，但不作为长期记忆。
- 当前已接入登录和管理员权限，MCP 配置由管理员维护；尚未实现租户隔离。
  面向多用户业务部署时还需完善业务身份传递与数据隔离。Skills 配置见 agent-configuration.md。

## 代码入口

- chat/AgentChatService.java：模型与工具的循环
- chat/OpenAiChatClient.java：工具定义发送和 tool_calls 解析
- tool/ToolExecutor.java：唯一工具执行入口，授权 / 校验 / 审计
- tool/ToolRegistry.java：服务配置、发现与 Agent 授权
- tool/ToolNetworkGuard.java：并发、频率和超时
- tool/OutboundPolicy.java：HTTP(S) 地址格式校验
- mcp/McpConnector.java：官方 MCP Java SDK 客户端
- db/migration/V4__tool_gateway.sql：数据库结构
- demo/mcp-server.mjs：本地只读协议演示

测试使用本地 HTTP 协议服务和模拟模型响应，不调用付费模型。
设置 PLATFORM_TEST_DB_URL / USERNAME / PASSWORD 后可运行 PG 集成测试。

## 自定义鉴权 Key
注册或编辑服务时选择「自定义请求头」，填写鉴权 Key（如 X-API-Key）和 Value。Value 加密保存，首尾空白去除，不自动添加 Bearer 前缀。修改时留空保留密钥；更换地址、鉴权方式或 Key 时需重新填写 Value。「无鉴权」会清除原密钥。旧服务保持 Bearer 行为。

## 按 MCP 服务绑定
智能体在详情页勾选 MCP 服务，无需逐个绑定工具。绑定后包含服务下所有已启用且仍可发现的工具，新同步的工具自动可用。工具或服务停用后不可调用，解绑服务会撤销该服务所有工具权限。
V8 迁移将旧工具绑定转换为所属服务绑定。GET / PUT /api/agents/{id}/mcp-servers 查询或替换服务绑定，PUT 请求体为 {"serverIds": ["服务 UUID"]}。GET /api/agents/{id}/tools 可查看已绑定服务的工具；旧 PUT 工具绑定接口已移除。
