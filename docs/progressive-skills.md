# 渐进式 Skills 与资源文件

运行开始时只将已绑定且启用的 Skill 名称、UUID 和用途提供给模型。
模型通过 load_skill 取得完整指令及资源目录，再通过 read_skill_resource 按路径读取参考材料。
读取结果作为工具消息进入本轮上下文，后续模型调用可继续使用；新的一轮按需重新加载。
不使用向量检索。已有 Skill 自动切换为按需加载，无需重建，但建议补全用途和触发条件。

## 文件管理

Skills 管理支持创建、修改 Markdown 主指令，添加 references/ 下的 UTF-8 文本，
以及 assets/ 下的模板、图片和其他附件，scripts/ 下的脚本文件（仅存储与读取，不执行）。目录导入需要根部 SKILL.md；
支持常见 name、description 元数据（普通、带引号、块文本），导入后须核对草稿再保存。
只接收主文档和 references、assets、scripts 文件；不支持任意 YAML 元数据的完整往返、
ZIP 导入、其他扩展目录或脚本执行。

SKILL.md 正文沿用 8,000 字符限制；最多 32 个资源文件，单文件 1 MB，总计 4 MB。
资源与指令原子保存，编辑时未改动的资源会保留；可移除或替换资源，点击保存后生效。
可下载 SKILL.md 和单个资源；下载文件内容不会在浏览器执行。
文本资源返回最多 12,000 字符并标注截断。
二进制资源只返回路径、类型和大小，不把 Base64 发给模型；可在管理页下载。
这一阶段不解析图片、PDF、Excel，也不把附件自动传入 MCP。
脚本文件可导入和编辑，但不能执行。

## 运行与轨迹

仅允许加载本轮配置快照中已绑定且启用的 Skill；读取资源前需要先加载主指令。
路径仅限 references/、assets/ 和 scripts/，拒绝绝对路径、相对跳转和重复路径。
配置和资源在短事务中生成一致快照，运行期间更新从下次请求生效。
文件保存在 PG，运行时不访问服务器任意文件系统。

需要绑定支持工具调用的模型。关闭工具调用或工具次数为 0 时不能按需加载 Skill。
内置加载和 MCP 调用共享最大工具次数、最大模型调用次数、任务超时及失败策略。
调用轨迹以“加载 Skill 指令”“读取 Skill 资源”节点显示输入、输出和耗时；
模型请求仍显示 Token，用量不会重复计入。
纯参考查询不需要绑定 MCP；执行真实业务查询仍需要单独绑定对应 MCP。

## API

- POST /api/skills/packages：创建指令与资源包。
- PUT /api/skills/{id}/package：原子替换指令与完整资源列表。
- GET /api/skills/{id}/resources：管理端读取资源（包括 Base64）。
- 原有 Skill 和绑定接口继续兼容；原有编辑接口不清空资源。

API 文件格式：path、mediaType、contentBase64；管理端返回 sizeBytes。
接口沿用登录和 CSRF 保护，Skills 仍为共享工作空间资源。

## 验证

真实 PG 集成测试使用模拟模型验证三次模型请求：
选择加载 Skill → 读取参考文档 → 返回最终回答，不调用真实模型。
同时覆盖资源权限、非法路径、重复资源、非文本 references、替换与运行快照。
前端文件测试覆盖元数据导入、Unicode、二进制和大小限制；
界面编辑与保存通过独立模拟接口验证。

可直接导入示例目录 demo/skills/mould-transfer；示例仅给出查询规范，不预设真实业务状态。

## 文件编辑工作台

左侧目录树切换 SKILL.md、references、assets 和 scripts，支持嵌套目录展开。
工作台最上方编辑 Skill 编码、名称和描述，下方左侧目录树、右侧当前文件编辑器；二进制附件显示文件信息、下载入口。
文件内容直接更新草稿，切换文件不丢失内容，顶部“保存 Skill”统一保存。
保存后保持当前 Skill 和当前文件；目录导入创建新草稿。已有 Skills 在独立列表页以卡片选择进入编辑。

## Skills 列表与编码

Skills 管理默认打开独立列表页；新建页面为 #/skills/new，编辑页面为 #/skills/{id}，刷新和浏览器返回保持路由。
编码、名称、描述位于文件工作台上方，保存后可返回列表。编码独立于显示名称，使用小写字母、数字与连字符，最长 64 字符且全平台唯一。
已有记录迁移生成 skill-加 UUID 的编码，原有缺少编码的接口调用继续兼容，更新不会覆盖原编码。
下载 SKILL.md 时 name 元数据使用编码；导入时可以分别调整编码和显示名称。

资源文件可在右侧工具栏重命名，保留原始内容和文件类型，统一保存后生效。SKILL.md 名称固定。重命名后需同步更新指令中的引用路径。

新建资源文件：先选中目录，再点击“新建文件”，只输入文件名，回车或点击“创建文件”。文件夹的选择和展开/折叠是独立操作。

## 新建文件夹

新建 Skill 默认仅有 SKILL.md，左侧提供“新建文件”和“新建文件夹”两个按钮。
创建文件夹可选择 references、assets、scripts，默认 references；选择文件夹后输入文件名创建文件。
空文件夹与资源包一起保存在 PG，刷新后仍保留。GET /api/skills/{id}/folders 返回目录列表，包保存 API 支持 folders 字段。
旧接口未提供 folders 时保留已有目录，并从资源路径补齐目录。脚本仍不执行。

目录标题下方提供新建文件、新建文件夹图标，悬停或键盘聚焦显示文字提示。已移除单文件上传及附件替换入口，目录包导入仍可使用。
